# Cirreum

Home of the Cirreum Framework — layered simplicity for modern .NET.

**v1.0 is released.** The full framework is published on NuGet at [nuget.org/profiles/cirreum](https://www.nuget.org/profiles/cirreum), with source across the [Cirreum org](https://github.com/cirreum).

This is the `.github` repository for the [Cirreum organization](https://github.com/cirreum). It holds org-wide assets:

- **[profile/README.md](profile/README.md)** — the organization profile shown at [github.com/cirreum](https://github.com/cirreum): overview, quick start, and the full repo-by-repo package catalog.
- **[Package-Layout.md](Package-Layout.md)** — the layered package architecture (Base → Common → Core → Infrastructure → Runtime → Runtime Extensions) and the main-track / provider-track model.

## Getting started

```bash
dotnet add package Cirreum.Runtime.Server
```

See the [profile README](profile/README.md) for the quick start and the [package layout](Package-Layout.md) for how the pieces fit together.
